# 핸드오프: 사주 결과 화면 리디자인 (다크 한지 · 오방색)

## 개요 (Overview)
사주(명리) 앱의 **결과 화면**을 리디자인한 패키지다. 원래 화면은 만세력·오행·십신·대운/세운·AI 해석이 한 화면에 평평하게 쌓여 위계 없이 읽기 어려웠다.
이 리디자인은 정보를 **위계화**하고 **탭으로 분리**했으며, 사주 용어를 **탭→상세 시트**로 풀어주고, 모바일까지 반응형으로 대응한다.

핵심 방향:
- **다크 + 한지/먹 질감**의 동양적이되 고급스러운 톤
- **채도 낮춘 오방색**을 오행(목·화·토·금·수)에만 절제해서 사용
- **메인은 단순하게**(항상 보이는 원국 + 핵심), **마니아 디테일은 탭 안에**(만세력 풀테이블)
- **용어 설명은 툴팁이 아니라 탭→상세 시트**(데스크탑 우측 드로어 / 모바일 바텀시트)

대상 사용자: 1999.04.04 05시생 남자 "유승민" 한 명의 샘플 데이터로 구성됨.

## 디자인 파일에 대하여 (About the Design Files)
이 번들의 파일들은 **HTML로 만든 디자인 레퍼런스**다 — 의도한 외형과 동작을 보여주는 프로토타입이지, 그대로 복붙할 프로덕션 코드가 아니다.
React 18 + 인-브라우저 Babel + 인라인 스타일로 빠르게 만들었다(빌드 도구 없음). **실제 코드베이스의 환경(React/Vue/SwiftUI/네이티브 등)과 기존 패턴·디자인시스템에 맞춰 재구현**하는 것이 목표다. 아직 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 골라 구현하면 된다.

> 인라인 스타일 → 실제 구현에서는 CSS Modules / styled-components / Tailwind / 토큰 시스템 등 코드베이스 관례로 옮길 것. 아래 **디자인 토큰** 섹션에 모든 값이 정리돼 있다.

## 충실도 (Fidelity)
**High-fidelity (hifi).** 최종 색상·타이포·간격·인터랙션이 모두 확정된 픽셀-정확 목업이다. 코드베이스의 기존 라이브러리/패턴으로 **픽셀 단위로 재현**할 것.

## 인터랙션 & 동작 (Interactions & Behavior)

### 탭 전환
- 클릭 시 `tab` 상태 변경, 콘텐츠 교체. 활성 탭은 정확히 하나만 채워져야 함(위 backgroundColor 주의).

### 용어/글자 → 상세 시트 (핵심 패턴)
**툴팁 금지.** 모바일에 hover가 없고 설명이 길기 때문. 대신:
- **데스크탑**: 우측에서 슬라이드-인 드로어. `position:fixed; top:0; bottom:0; right:0; width:440px`. `transform: translateX(101%→0)`, transition `.26s cubic-bezier(.2,.7,.3,1)`. 뒤에 딤 오버레이 `rgba(8,6,4,0.62)` + `backdrop-filter: blur(3px)`, opacity 0→1.
- **모바일**: 하단에서 슬라이드-업 바텀시트. `left:0;right:0;bottom:0; border-radius:16px 16px 0 0; max-height:86vh; overflow-y:auto`, `transform: translateY(101%→0)`. 상단에 그랩 핸들(40×4, radius 2).
- 닫기: 오버레이 클릭, × 버튼, **Esc 키**.
- **트리거 대상**:
  1. 천간/지지 글자(원국·만세력·대운) → 글자, 한자, `오행·음양`, 이미지/동물 칩 + 블록(십신 뜻, 자리(궁) 의미, 지장간 목록)
  2. 점선 밑줄 용어(격국/용신·기신/신강약/운성/지장간/통근/사령신/오행/대운) → 용어, 한자(`格局` 등), 정의 본문
- **어포던스**: 글자엔 `cursor:pointer` + hover 시 오행색 글로우(`text-shadow`). 용어엔 `border-bottom: 1px dotted ink28`. 8자 카드 헤더에 `글자를 누르면 뜻이 나와 ⓘ` 힌트.

### 글자 hover
- 천간/지지 글자에 마우스 올리면 `text-shadow: 0 0 22px {오행 soft색}` 추가.

### 반응형
- 브레이크포인트 **768px** (`max-width:767px` → 모바일). `window.matchMedia`로 감지, 리사이즈 시 갱신.
- 모바일에서: 모든 2단 그리드 → 1단, 패딩/폰트 축소, 탭바 가로 스크롤, 상세 드로어 → 바텀시트.

## 상태 관리 (State Management)
- `tab`: 현재 활성 탭 id (`'ai'|'manse'|'ohaeng'|'daeun'|'olhae'|'gunghap'`), 기본값 `'manse'`.
- `detail`: 열린 상세 시트의 payload 객체(또는 null). `null`이면 시트 닫힘.
- `isMobile`(`m`): `useIsMobile()` 훅이 `matchMedia`로 관리.
- 컨텍스트 `SajuUI`로 `{ m, openDetail }`를 하위에 전달(prop drilling 회피).
- **데이터 페칭**: 현재는 정적 샘플(`SAJU` 객체). 실제 구현에선 사주 계산 엔진/API 응답으로 이 객체만 교체하면 전 화면이 반영됨.

상세 payload 형태:
```
{ head: '정', han: '丁', oh: '화'|null,
  chips: ['화 · 음(陰)', '등불·촛불'],
  blocks: [{ label: '십신 — 정관', text: '...' }, ...] }
```

### 타이포

- **라벨/숫자/마이크로카피**: `IBM Plex Mono` (400·500), letter-spacing 1~3, 종종 uppercase.

- 컨테이너 패딩 데스크탑 `40px 44px 64px` / 모바일 `20px 15px 48px`.
- 섹션 간 gap 16~24, 그리드 gap 10~24.
- 그림자: 상세 시트 `0 -10px 60px rgba(0,0,0,.6), 0 10px 60px rgba(0,0,0,.6)`. 그 외엔 그림자 거의 없음(테두리+면으로 구분).

모든 콘텐츠는 `saju/tokens.jsx`의 `SAJU` 객체 하나에 있다. 실제 사주 엔진 출력으로 이 객체만 교체하면 전 화면 반영.
- `ilgan`(일간), `meta`(격국/용신/기신/신강/자비%), `ohaeng`(오행%), `pillars`(8자, 시·일·월·년 순), `detail`(사령신/합/공망/신살), `seun`(세운 2026·2027), `daeun`(7개)·`daeunMeta`, `trait`(강점/주의), `ai`(4개 해석).
- ⚠️ **격국·대운은 '추정' 표기**(샘플 추정값). 실제 계산값으로 교체할 것.

## 파일 (Files)
| 파일 | 내용 |
|---|---|
| `사주 결과 v2.html` | 진입점. 폰트 로드 + React/Babel + 4개 jsx 로드 순서(tokens → detail → panels → saju-app) |
| `saju/tokens.jsx` | 디자인 토큰(INK/OHAENG), `SAJU` 데이터, `hanjiURL()`, 공용 atom(Mono/KoLabel/Seal/SectionHead/Hair), `useIsMobile()`, `SajuUI` 컨텍스트 |
| `saju/detail.jsx` | 용어 사전(SIPSIN/CHEONGAN/JIJI/ROLE/UNSEONG/GLOSS), payload 빌더(buildGan/buildJi/buildTerm), 탭 가능 컴포넌트(Term/TapChar), 상세 시트(DetailSheet) |
| `saju/panels.jsx` | 탭 패널 6종(ManseTab/AiTab/OhaengTab/DaeunTab/OlhaeTab/GunghapTab) + 공용(Panel/MetaRow/OhaengBar) |
| `saju/saju-app.jsx` | 앱 셸: 상단바 + 원국(WonGuk) + 탭바 + 콘텐츠 + 컨텍스트 제공 + DetailSheet 마운트 |

> 각 `<script type="text/babel">`는 스코프가 분리되므로, 공유 컴포넌트/함수는 파일 끝에서 `Object.assign(window, {...})`로 전역 노출한다(실제 코드베이스에선 정상적인 import/export로 옮길 것).
