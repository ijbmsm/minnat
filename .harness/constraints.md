# 제약

번호는 `M-NN` 으로 고정한다. charzing 의 `C-NN` 과 섞이지 않게 접두를 다르게 뒀다.

> 문서에 "반드시 X" 를 적을 거면 **확인할 검사를 같이 만든다.**
> 못 만들면 "권장" 으로 낮춘다. 검사 없는 규범은 지켜지지 않는다.

## M-01 — 점수 규칙은 두 리포에서 같아야 한다

**검사**: `score-parity` · **상태**: 켜짐 (baseline 3건, 기한 2026-10-09)

크롤러(`minnat-crawler`)가 계산해 DB `weighted_score` 에 넣는 점수와, 웹(`minnat`)이
화면에서 다시 계산하는 점수가 같은 규칙을 따라야 한다.

**정본은 웹이다** (2026-09-25 결정). `CLAUDE.md` 의 점수 공식도 웹과 같다.

```
저장 (크롤러) = min(base × diversity × position_weight × 100, 100)
화면 (웹)     = 저장값 × viewDecay(view)
```

`decay` 는 저장하지 않는다. 뷰별 곡선이 4개(`hot`·`recent`·`midterm`·`alltime`)고
"지금" 에 의존해서, 저장하면 다음 날 틀린 값이 된다. 렌더 시점에만 곱한다.

### 왜 기계가 봐야 하나

두 숫자가 각각 다른 화면에 나온다.

| 숫자 | 계산 | 어디에 |
| --- | --- | --- |
| `weighted_score` | 크롤러 `scorer.calculate_score` | 매일 찍히는 진영 스냅샷 ("파랑 37% vs 빨강 63%") |
| 화면 점수 | 웹 `calculateIssueScore` / `calculateEventScore` | 홈 · 이슈 목록 · 정치인 페이지 · 정렬 |

규칙이 갈려도 **화면 어디에도 그 사실이 안 보인다.** 한쪽 PR 만 보는 사람은
영원히 모른다. 2026-09-25 실측에서 이미 갈라져 있었다 — 크롤러에 다양도와
상한이 빠져 있었고, 크롤러 독스트링조차 코드와 달랐다.

### 무엇을 보는가

1. `CRIMINAL_STAGE_WEIGHT` · `MEDIA_LEAN` 의 키와 값이 두 리포에서 같은가
2. 진영 다양도 계단값(0.7 / 1.0 / 1.3)이 같은가
3. 크롤러 최종 점수식이 다양도와 100 상한을 포함하는가

### 무엇을 안 보는가

- **`decay`** — 저장할 수 없으므로 비교 대상이 아니다
- **`POSITION_WEIGHT`** — 웹에 정의는 있으나 **읽는 코드가 없다**
  (2026-09-25 실측: `constants.ts:62` 정의 외 참조 0건). 실제로는 크롤러가
  계산해 DB 에 넣은 `issue.position_weight` 를 쓴다. 지금 검사에 넣으면
  "웹에 5개가 없다" 는 위반이 뜨는데 고칠 방법이 죽은 상수를 지우는 것뿐이다.
  **죽은 정의를 지운 뒤에 넣는다.**

## 아직 검사가 없는 것

규범으로 적을 만하지만 확인할 방법을 아직 안 만들었다. **적기 전에 검사부터 만든다.**

| 후보 | 근거 | 왜 아직 안 만들었나 |
| --- | --- | --- |
| 사안 등급 규칙 일치 | `CLAUDE.md`: 등급 규칙이 `storyline_shape.event_grade`(Py)와 `lib/story-format.deriveGrade`(TS) 양쪽에 있다 | M-01 과 같은 모양이다. 검사 하나를 굴려보고 나서 이어 붙인다 |
| LLM 호출 규율 | `analyzer.py` 가 `stop_reason` 을 안 본다 — 응답이 잘리면 "JSON 파싱 실패" 로 뭉개져 기사가 통째로 버려진다 (2026-09-25 실측 130건 중 3건) | 개편 4단계에서 호출부를 쪼갤 예정이라, 그 구조가 정해진 뒤에 만든다 |
| 월 LLM 예산 상한 | 웹 사주는 `spend.ts` 에 월 800회 킬스위치가 있는데 크롤러는 실행당 예산만 있고 누적 상한이 없다. 2026-09-22 크레딧 소진으로 크롤러가 2.5일 무중단 0건 | 상한을 어디에 둘지가 먼저다 |
| 품질 장치 배선 여부 | `validator.py` · `bias_audit.py` · `cross_verify.py` · `storyline_builder._fingerprint` 가 정의만 되고 실행 경로에 없다 (2026-09-25 실측: `validation_status` 342건 전부 `pending`) | 파이썬 import 그래프를 봐야 한다. 정규식으로는 부족하고 `ast` 가 필요하다 — 먼저 정규식으로 가능한 것부터 |
