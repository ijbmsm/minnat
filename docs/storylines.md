# 사안(Storyline) — 사건 위의 층

기사 → 사건(`issue_clusters`, 7일 윈도우) 위에 몇 년짜리 **사안**을 얹는다.
사람이 손대는 곳이 없다. 크롤러가 만들고 갱신한다.

## 왜 자동인가

처음엔 사람이 원고를 쓰고 후보를 승인하는 구조였다. 두 번 지적받고 뒤집었다.

- 승인 큐는 읽을 사람이 있어야 돌아간다. 없으면 큐만 쌓이고 기능이 멈춘다.
- "원고는 사람이 써야 한다"는 기준이 이 제품과 어긋났다 —
  기사 본문(`issues.summary`)은 이미 Haiku 가 써서 그대로 화면에 나간다.
  사안 원고만 다른 잣대를 댈 이유가 없다.
- 크롤링해놓고 사람이 쓸 거면 크롤링을 할 이유가 없다.

## 누가 무엇을 정하나

| 무엇 | 어디서 | 방식 |
|---|---|---|
| 어떤 사건이 한 사안인가 | `storyline_discover.py` | **규칙** — 희소 고유명사 2개 이상 공유 |
| 장을 어디서 자르나 | `storyline_shape.py` | **규칙** — 형사 단계 전환 · 보도 공백 120일 |
| 등급(확정/혐의/주장) | `storyline_shape.py` / `lib/story-format.ts` | **규칙** — `criminal_stage`·`source_tier` |
| 제목·본문·요지·slug | `storyline_author.py` | Haiku + 표현 검수 |
| 엮어서 DB 에 쓰기 | `storyline_builder.py` | — |

**등급과 장 구분을 LLM 에 맡기지 않는다.** 그건 사실관계고, 같은 입력에 매번 다른
답이 나오면 안 된다. 확정/혐의/주장이 섞여 나오는 게 이 제품이 메우려는 빈틈인데
우리가 다시 섞으면 존재 이유가 없다.

> 등급 규칙은 Python(`event_grade`)과 TS(`deriveGrade`) 양쪽에 있다.
> **한쪽만 고치면 화면 배지와 DB 장 등급이 서로 다른 말을 한다.**
> 테스트가 양쪽에 같은 표로 있다: `tests/test_storyline_shape.py`, `src/lib/__tests__/stories.test.ts`.

## 안전장치 — 사람이 아니라 규칙

1. **표현 검수** — `expression_filter` 를 통과해야 저장된다. 금지어가 남으면 사안을 만들지 않는다.
2. **날짜 조작 차단** — 입력에 근거 없는 날짜가 하나라도 있으면 원고 전체를 버린다.
   첫 시험에서 모델이 "헌법재판소는 12월 14일 파면했다"고 썼다. 실제 파면은 이듬해 4월이었다.
   우리가 넘긴 값이 **보도일**이었기 때문이다. 그래서 지금은 LLM 에 날짜를 아예 넘기지 않는다.
3. **인과 금지** — 사건 요약이 두 국면의 인과를 명시하지 않으면 시간 연결어만 쓴다.
   "이 보도로 검찰이 움직였다"는 없는 인과를 만드는 문장이고 서사에서 가장 위험한 자리다.
4. **틀린 건 막는 대신 내린다** — `hidden=true` 로 화면에서 뺀다.

## 발견 규칙을 왜 이렇게 정했나 (2026-09-19 실측)

임베딩으로 묶으려다 실패했다:

```
같은 사안  국정농단 ↔ 국정농단   0.342
           계엄 선포 ↔ 계엄 기소  0.335
다른 사안  계엄 ↔ 국정농단        0.377   ← 같은 사안보다 높다
```

같은 사안 0.24~0.75 / 다른 사안 0.17~0.38 로 겹쳐 **어떤 임계로도 갈리지 않는다.**
요약이 짧고 압축적이라 벡터가 표면 어휘에 지배된다.

고유명사 1개 공유로 바꿨더니 전이적으로 번져 95건 중 **66건이 한 사안**이 됐다
(윤석열↔박근혜↔이준석 — 인물 이름이 서로 다른 사안을 잇는다). 그래서 지금은:

- 인물 이름은 잇는 고리에서 **제외**
- 희소 고유명사 **2개 이상** 공유해야 연결
- 3년 이상 시간이 비면 분리 (세월호 2014 ↔ 이태원 2022 가 "대응·부재·참사"로 묶였다)

## 장은 사건이 아니라 **기사** 단위로 자른다 (2026-09-20)

처음엔 클러스터(사건) 단위로 잘랐다. 배포 후 보니 비상계엄 사안이 **1개 국면**이었다 —
실제로는 17개월짜리 서사인데.

원인: 클러스터의 `first_reported_at` 은 **최초 보도일** 하나라, 2024.12 ~ 2025.5 에 걸친
기사 9건이 한 점으로 눌렸다. 국면이 바뀌는 지점(기소 → 탄핵소추 → 파면 → 재판)은
클러스터가 아니라 **기사 날짜**에 있다.

`_articles_of()` 로 사안을 이루는 클러스터의 기사를 전부 모아 그 위에서 자른다.

| | 전 | 후 |
|---|---|---|
| 비상계엄 | 5건 · 1국면 | **9건 · 3국면** (선포 → 기소·탄핵소추 → 파면·재판) |
| 조국 | 2건 · 1국면 | **5건 · 4국면** (기소 → 1심 → 2심 → 대법 확정) |

같은 달 안에서 국면이 나뉘면 라벨이 겹치므로(`2024.12` × 2) 일까지 표시한다.

## 제도적 결정은 형사 단계가 아니다 (2026-09-20)

`criminal_stage` 는 형사 절차(수사→기소→1심→…→확정)만 모델링한다. 국회 탄핵소추
가결이나 헌재 인용·기각은 형사 절차가 아닌데 담을 어휘가 없어, 분류기가 억지로
형사 단계를 골랐다. 같은 종류의 결정이 제각각으로 저장돼 있었다:

| 기사 | category | criminal_stage |
|---|---|---|
| 노무현 탄핵 — 헌재 기각 | ethics_violation | dismissed |
| 윤석열 국회 탄핵소추안 가결 | criminal_conviction | investigation |
| 윤석열 헌재 탄핵 인용 파면 | criminal_conviction | **indicted** ← 확정인데 '혐의' |
| 이상민 탄핵소추 헌재 기각 | official_misconduct | (없음) |

그 결과 사안 화면에서 **"헌재 전원일치 파면"이 근거등급 '혐의'** 로 표시됐다.
확정된 제도적 결정을 혐의로 적으면 이 제품이 메우려던 빈틈을 우리가 다시 만든다.

`institutional_stage` 를 신설했다(마이그레이션 028). 형사 절차와 **다른 축**이고
한 기사가 둘 다 가질 수 있다. 등급 판정에서는 **제도 쪽이 우선**한다 — 헌재 파면
기사에 형사 기소 단계가 함께 붙어 있어도, 그 기사가 기록하는 것은 제도적 결정이다.

```
impeachment_proposed  탄핵소추안 발의
impeachment_passed    국회 가결 → 직무정지
impeachment_upheld    헌재 인용 → 파면 (종국)
impeachment_rejected  헌재 기각·각하 (종국)
censure_passed        해임건의안 가결
inquiry_launched      국정조사·특검 발동
```

기존 행은 `backfill_institutional_stage.py` 로 한 번 채운다(제목 키워드 규칙).

## 운영

```bash
python storyline_builder.py            # 드라이런 — 무엇을 만들지만 출력
python storyline_builder.py --apply    # 실제 생성
```

크롤러 파이프라인 `[7] 사안 재구성` 단계에서 자동 실행된다. 실패해도 수집은 계속된다.

사안은 매번 **통째로 다시 만든다.** 사건이 늘면 장 경계가 바뀌므로 증분 갱신이
오히려 어긋나기 쉽고, 사안이 수십 개 규모라 다시 쓰는 편이 싸고 정확하다.

## 발견 규칙을 다듬으며 겪은 것 (2026-09-20 첫 생성)

첫 생성 결과를 보고 네 군데를 더 고쳤다. 전부 **실제 출력에서 드러난** 문제다.

| 증상 | 원인 | 처치 |
|---|---|---|
| 김승원 사안이 3조각 | `김승원` 이 95건 중 18건(19%)에 나와 **DF 상한 15% 초과로 탈락**. 정작 그 사안을 특정하는 유일한 낱말인데 "흔한 말"로 분류됐다 | DF 상한 0.15 → **0.35**. 고리를 2개 요구하므로 흔한 말 하나로는 못 잇는다 |
| 청년정책 + 중앙아시아 외교가 한 사안 | 병합 단계에서 `이재명`+`이준석` **인물 이름만으로** 합쳐졌다 | 공유 낱말 중 최소 하나는 비인물이어야 한다 |
| 이태원 참사(2022) + 비상계엄(2024)이 한 사안 | `윤석열` 을 공유한다는 이유로 병합 | 두 사안의 기간이 **180일 넘게 벌어지면 병합 금지**. 쪼개진 같은 사안은 늘 시간이 붙어 있다 |
| 종결 사안 기간이 "175일간" | `ended_at` 이 마지막 사건의 **보도일**이라 실제 종결일이 아니다 (국정농단은 2016~2021 사안) | 종결 사안은 **연도 범위**만 표시 (`2016 – 2017`). 일 단위 정밀도를 주장하지 않는다 |

결과: 사안 16개 — 비상계엄 · 김승원 · 다스 · 국정농단 · 조국 · 드루킹 · 도이치모터스 ·
이태원 · 명태균 · 채상병 · 의대증원 · 대장동 · 공직선거법 등. 전부 로마자 slug.

## 남은 것

- `EVENT_MATCH_THRESHOLD` 는 0.85 → 0.78 로 내렸다. 사안 발견 품질이 사건 중복에
  직접 영향을 받기 때문이다(2건짜리 사안 상당수가 서로 중복이었다).
- 인물 역할 서술에 미세한 드리프트가 있다("비서실장"→"정책실장"). 날짜만큼 위험하진
  않지만 같은 방식의 근거 검사를 붙일 수 있다.
